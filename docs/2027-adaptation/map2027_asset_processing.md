# 2027 地图资产处理记录

处理时间：2026-11-12～13。范围是可复现的场地图纸转换与参考资产导出，尚未接入比赛默认配置或完成现场定位验收。

## CAD 来源与转换

来源、校验值和版本见 [STEP 初检](map2027_step_intake.md)。使用用户提供的 RMUC2027 V1.0.0 STEP，长度单位为毫米；脚本在导入前核对整个源文件 SHA-256，拒绝静默处理其他版本。

已用 OpenCascade/OCP 7.9.3.1 转换装配、颜色和实例位置。84 条装配引用展开为 81 个叶子实例。释放 STEP 解析数据后再网格化，避免解析图与三角网格同时占用过多内存。线性网格偏差参数为 5 mm，角度参数为 0.25 rad；这两个参数不是现场定位误差承诺。

glTF 缓存按部件合并面，保留 81 个网格对象、286 个材质图元。CAD 毫米坐标显式转换为 glTF 米坐标：`(X, Y, Z)_glTF = (X, Z, -Y)_CAD / 1000`。VTK 9.1.0 在独立进程中进行正交渲染。

## 场地边界与坐标约定

规则手册 V1.0.0 正文 P29 标称战场 28 m × 15 m，P33 说明尺寸以倾斜面为基准标注。CAD 两个大地面上表面分别测得约 1.5°。地面完整对象的宽度超过 16 m，不能把它的整个外框直接缩放成 15 m。

本版参考资产采用地面 X 边界、地面中轴线，以及标称宽度沿斜面的投影确定裁切范围：

| 项目 | CAD 毫米值 |
|---|---:|
| X 最小值 | -13999.988539 |
| X 最大值 | 14000.002952 |
| Y 中轴线 | 1624.343677 |
| Y 最小值 | -5873.086261 |
| Y 最大值 | 9121.773614 |
| 15 m 倾斜面对应水平投影宽度 | 14994.859875 |

将该矩形归一化至 2800 × 1500 cm 参考坐标。Y 方向包含显式的斜面长度校正，不能简单对 CAD 全部 XY 坐标统一除以 10。三阶齐次矩阵及逆矩阵保存在资产清单；高度独立保存为 CAD 绝对 Z 毫米值，不混入厘米平面坐标。

参考原点取红方补给站一侧的场地角点，X 朝蓝方，Y 朝红方上侧角点。对应仓库现有坐标显示方式：

| 图像 | 尺寸（宽×高） | 连续图像边界坐标 `(u, v)` |
|---|---|---|
| 横向，红左蓝右 | 2800 × 1500 | `(X_cm, 1500 - Y_cm)` |
| 红方在下 | 1500 × 2800 | `(1500 - Y_cm, 2800 - X_cm)` |
| 蓝方在下 | 1500 × 2800 | `(Y_cm, X_cm)` |

像素中心对应索引加 0.5，边界坐标不等于数组最后一个像素索引。上述裁切与坐标约定属于图纸参考模型，仍需要现场已知点和真实裁判坐标核验，不应写成已完成物理标定。

## CAD 参考资产

位置：`vision/images-2027/cad-v1.0.0/`。

- `topdown.png`、`red_bottom.png`、`blue_bottom.png`：三种正交视图，保留 CAD 色块与丝印。STEP 未检出纹理、图像或外部贴图引用，因此这些图没有手册渲染图的地胶材质外观。

- `height_preview.png`：带坐标的高度检查图，色标上限截在 1200 mm；NPZ 原始高度未截断。

后续已基于 CAD 网格制作带版本的多类区域、坡面与结构审阅掩码，详见 [地形候选分区记录](map2027_terrain_regions.md)。这些产物保留地胶显示图作对照，尚未直接接入旧两层投影。

## 复现 CAD 资产

建议使用独立 Python 环境，依赖见 `tool/requirements-map2027.txt`。本次实际使用 Python 3.10、OCP 7.9.3.1、VTK 9.1.0；VTK 使用可访问的 X 显示执行离屏渲染。无 X 环境需要相应的 EGL/OSMesa 构建或虚拟显示，不能假定所有 VTK 安装均可纯无头渲染。

从仓库根目录运行：

```bash
python3 tool/export_2027_map.py mesh
python3 tool/export_2027_map.py render
```

两步分进程执行。默认缓存位于已忽略的 `tool/data/map2027/`；原始 STEP 与大体积 glTF 缓存不纳入本次资产提交。`--step`、`--cache`、`--output` 可指定输入和输出路径。

## 保留地胶的显示底图

按用户要求，显示底图使用官方手册图 4-1 中已有的地胶外观，不使用缺少纹理的 CAD 色块图代替。原始 JPEG 的像素未重绘；原始数据直接嵌入 SVG，通过显式的仿射矩阵裁去白边、围挡外框并对齐 CAD 参考画布，然后由 Qt QSvgRenderer 渲染 PNG。没有生成或补画地胶纹理。

位置：`vision/images-2027/display-v1.0.0/`。

- `topdown.png/.svg`：横向 2800×1500，红左蓝右，保留官方地胶、标线和渲染外观。
- `red_bottom.png/.svg`、`blue_bottom.png/.svg`：红方在下、蓝方在下的 1500×2800 显示图。SVG 内嵌同一份原始 JPEG，不依赖外部图片路径。
- `registration.json`：配准矩阵、匹配坐标、误差和四象限覆盖记录。
- `alignment_check.svg`：绿色圆圈为配准后的官方图点，红点为 CAD 匹配点，黄色线段为残差，供人工复核。
- `manifest.json`：原始 JPEG、CAD 清单和每个输出文件的校验值，以及 SVG 渲染器版本。

用 OpenCV 4.8.0 的 SIFT 特征、0.7 描述子距离比和仿射 RANSAC 对齐；5 CAD 像素的门槛筛出 22 个内点，四象限分别为 5、5、7、5 点。配准残差中位数 1.353、最大值 3.968 个导出像素；内点留一检查残差中位数 1.497、最大值 4.630 个导出像素。这些是图片配准残差，不是相机定位精度，也不表示整张官方渲染图与所有 CAD 高度面严格重合。

原图仅 981×559 像素，实际场地区域更小。导出 2800×1500 只用于匹配现有画布，不增加原始纹理细节。CAD 几何和官方渲染外观分别保留；后续若有高清官方俯视图，应按新来源版本重新配准，不能使用生成式补画结果作为几何依据。

依赖见 `tool/requirements-map2027-display.txt`。已提交的 CAD 参考资产足以完成显示图处理，此步骤不需要重新加载 STEP 或安装 CAD 内核。从仓库根目录运行：

```bash
python3 tool/prepare_2027_display_map.py
```

可通过 `--reference`、`--cad`、`--output` 指定路径。输入校验值与已核对版本不一致时拒绝导出。显示坐标公式与上表相同，默认比赛地图配置仍未切换。
