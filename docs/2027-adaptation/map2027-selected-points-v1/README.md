## 仍需现场确认的含义

- 两层是用户本次点位分组，不意味着每组已经证明共面；没有用新的候选点求解单应矩阵或相机 R/t。
- L2-3 按用户要求保留蓝色轮廓外侧角。原始彩色几何中可定位该蓝线顶点，归属中央装配区部件；并未把它改成中央高地地面点。其 Z 也按实际网格顶点记录，不虚构统一高层高度。
- L2-5 固定为公路上表面内缘角点；邻接隧道挡边在几乎相同 XY 处具有不同 Z，现场需按局部图确认观察的是对应公路角点。L1-1、L1-3、L1-5 应选接地边，而非坡顶或结构上缘。
- 地胶底图来自低分辨率官方俯视图的配准，允许与 CAD 特征存在小范围视觉偏差；图纸定义、实体搭建和相机可见性仍需现场核验。原图尺寸扩大不增加真实纹理细节。
